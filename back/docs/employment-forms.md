# Formatos postulaciones

- Public form: `https://futsi.bpoweracademy.mx/#/postulacion`; optional exam capability suffix pre-fills and scopes the vacancy. No contact values in URLs.
- HR sidebar: **Formatos postulaciones**, `#/examenes/formatos-postulaciones`. General/exam links, copy/open, list, text/position/link filters, paginated records and full details.
- The schema preserves the 78 original employment PDF fields and adds email and typed applicant name. Sensitive demographic/health fields are optional, collapsed and require separate explicit consent. No eligibility/ranking decisions use these fields.
- Django API: public schema GET and write-only POST `/api/public-employment-form/`; private HR GET list/detail and POST explicit link `/api/recruitment-applications/` and `/<id>/`. Public responses contain receipt/time only, never applicant data or matches.
- `0074_recruitment_applications` creates private text/JSON storage with RLS and zero PUBLIC/anon/authenticated grants. No PDF binaries or Storage objects. Nullable profile updater denotes public provenance; the originating application retains its own record/receipt.
- UUID submission keys prevent duplicate submissions on network/manual retries. Final submissions are immutable. Validation, a honeypot and bounded public throttle apply. No automatic network retries or polling, workers, cron or AI.
- Linking runs synchronously on form submission and exam delivery/expiry. Automatic linking requires one submitted exam for the same vacancy and matching normalized email **and** phone. Ambiguous/conflicting matches stay for HR review; unrelated vacancies never cross-link. A later exam can link an earlier form. Existing CV, grades, saved position and existing imported form are never overwritten.
- Vero's WhatsApp service sends the general link, once after a qualifying recruitment-template reply within 24h, replacing the automatic PDF. Opt-outs, quoted-message checks and durable dispatch guards remain. Failures/uncertainty are stored without retry. Existing PDF recipients are not automatically sent another link. Deployment itself sends nothing.
- Tests use fictional local-only data; no candidate WhatsApp messages are sent by QA. Keep the legacy import workflow for previous PDF/TXT files.
